## Phase 2: Billing Computation

| # | Task | Responsible | Status | Date |
|---|------|-------------|--------|------|
| 2.1 | ☐ Navigate to **Progress Billings** and select the project | Finance Officer | | |
| 2.2 | ☐ Select the **billing period** | Finance Officer | | |
| 2.3 | ☐ The system pulls approved accomplishment data automatically | — | | |
| 2.4 | ☐ Review each line item: | Finance Officer | | |
|    | — BOQ item description and reference | | | |
|    | — Contract unit price | | | |
|    | — Cumulative quantity accomplished | | | |
|    | — Previous billing amounts | | | |
|    | — Current billing amount = (Cumulative × Price) − Previous | | | |
| 2.5 | ☐ Verify the **billing template** is correct for the client | Finance Officer | | |
| 2.6 | ☐ Apply the **retention percentage** (typically 10%) | Finance Officer | | |
| 2.7 | ☐ Calculate: | Finance Officer | | |
|    | — **Gross Billing** = Sum of all current billing amounts | | | |
|    | — **Retention** = Gross Billing × Retention % | | | |
|    | — **Net Billing** = Gross Billing − Retention | | | |
|    | — **Cumulative Billing** = Previous + Current Net | | | |
| 2.8 | ☐ Verify **Cumulative Billing ≤ Revised Contract Amount** | Finance Officer | | |
| 2.9 | ☐ Verify **no duplicate billing** for previously billed accomplishments | Finance Officer | | |
