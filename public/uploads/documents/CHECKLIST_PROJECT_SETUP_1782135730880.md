# OneSystemsERP — Project Setup Checklist

**Document Code:** CKL-004  
**Version:** 1.0  
**Classification:** Internal — Project Managers, System Administrators  
**Effective Date:** June 2026  

---

## Instructions

This checklist must be completed for **every new project** added to OneSystemsERP. The System Administrator initiates the project shell, and the Project Manager completes the configuration. All items must be completed before project operations can begin.
