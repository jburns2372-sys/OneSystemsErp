## Phase 1: Material Request

| # | Task | Responsible | Status | Date |
|---|------|-------------|--------|------|
| 1.1 | ☐ Verify the **Consolidated BOQ is locked** | PM / Purchasing | | |
| 1.2 | ☐ Identify required materials from the BOQ | PM / PE | | |
| 1.3 | ☐ Check **Remaining Balance** for each item | Purchasing Officer | | |
| 1.4 | ☐ Verify requested quantities **do not exceed** Remaining Balance | Purchasing Officer | | |
