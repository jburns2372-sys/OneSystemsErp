# OneSystemsERP — New User Onboarding Checklist

**Document Code:** CKL-001  
**Version:** 1.0  
**Classification:** Internal — HR / Admin / All New Staff  
**Effective Date:** June 2026  

---

## Instructions

This checklist must be completed for **every new employee** granted access to OneSystemsERP. The HR Officer or System Administrator initiates the process. The new user and their direct supervisor must both sign off upon completion.

**Target Completion:** Within **5 business days** of the employee's start date.
