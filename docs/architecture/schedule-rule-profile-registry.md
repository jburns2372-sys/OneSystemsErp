# Schedule Rule Profile Registry

Create reusable versioned registries for schedule heuristics. All profiles and overrides must be versioned, auditable, project-scoped where required, approved before production use, and reproducible.

## A. Schedule Rule Profiles

Support at least the following disciplines/types:
- electrical
- civil
- mechanical
- plumbing
- fire protection
- ICT
- security systems
- supply and installation
- maintenance
- rehabilitation
- design and build
- mixed discipline

## B. Productivity Profiles

Fields may include:
- work-item classification
- unit
- baseline production rate
- crew type
- crew size
- equipment requirement
- calendar
- location factor
- weather factor
- complexity factor
- productivity source
- version
- approval status

## C. Procurement and Lead-Time Profiles

Fields may include:
- material type
- equipment type
- approval duration
- fabrication duration
- delivery duration
- inspection duration
- installation prerequisite
- supplier class
- location factor
