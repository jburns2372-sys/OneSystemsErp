# Multi-Project Acceptance Strategy

Do not classify the production intake and scheduling engine as universally deployable until it passes at least five materially different project fixtures.

## Required Fixtures

- **Fixture 1**: Electrical project using a structured Excel BOQ.
- **Fixture 2**: Civil project using a differently arranged Excel Program of Works.
- **Fixture 3**: Mechanical project using a native PDF BOQ.
- **Fixture 4**: Mixed-discipline project using multiple workbook sheets.
- **Fixture 5**: Small supply-and-installation project using a simplified source format.

Each fixture must have a different:
- source format
- column layout
- row count
- contract amount
- project duration
- disciplines
- category structure
- WBS count
- activity count
- dependency graph
- CPM result

## Required for Every Fixture

- complete source lineage
- canonical BOQ extraction
- zero financial difference
- no duplicate BOQ rows
- no missing BOQ rows
- valid authoritative checksum
- locked BOQ
- dynamically generated schedule
- complete BOQ allocation
- valid acyclic CPM network
- schedule inside contract period
- mandatory final acceptance phase
- authenticated actor provenance
- review and approval workflow
- baseline activation
- successful revision creation
- backup and restoration verification

Approve universal production deployment only after all multi-project acceptance criteria pass.
