## Instructions

This checklist covers the **daily, weekly, and monthly** responsibilities of the System Administrator. Use this as your operational playbook to ensure nothing is missed.

---

| # | Task | Time | Status | Notes |
|---|------|------|--------|-------|
| D1 | ☐ Verify application is running and responsive | 08:00 | | |
| D2 | ☐ Review **System Audit** log for overnight anomalies | 08:15 | | |
| D3 | ☐ Check **AI Command Center** for pending overrides or errors | 08:30 | | |
| D4 | ☐ Review **failed login attempts** for security threats | 08:45 | | |
| D5 | ☐ Process pending **user account requests** (new, changes, deactivations) | 09:00 | | |
| D6 | ☐ Resolve **access/permission support tickets** from staff | 09:30 | | |
| D7 | ☐ Verify **database backup** completed successfully | 12:00 | | |
| D8 | ☐ Review **active user sessions** for suspicious patterns | 14:00 | | |
| D9 | ☐ Check **server resources** (CPU, memory, disk space) | 15:00 | | |
| D10 | ☐ End-of-day **system status check** — log any unresolved issues | 17:00 | | |
